# Media slots

Bỏ ảnh/video vào đây, đặt tên đúng **id** hiển thị trên khung placeholder của trang demo
(vd. `home-hero.mp4`, `hope-kids-hero.jpg`). Build lại là khung tự thay bằng file thật.

- Ảnh: `.jpg .jpeg .png .webp .avif` — Astro tự nén/resize, cứ để ảnh gốc ≤ 3000px.
- Video: `.mp4` (H.264) hoặc `.webm`, không tiếng, 10–30s, ≤ 8 MB. Ảnh poster tuỳ chọn: `<id>-poster.jpg`.
- Chỉ dùng ảnh đã có đồng ý (trẻ em: có đồng ý của phụ huynh).
